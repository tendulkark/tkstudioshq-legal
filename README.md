# TK Studios HQ — Legal Pages

Public privacy policy pages for TK Studios HQ apps, served via GitHub Pages from `/docs`.
Kept in a dedicated public repo so each app's own source can stay private while its
legally-required privacy policy (needed for AdMob/UMP consent and Play Console submission)
stays reachable at a stable URL.

## Apps

| App | Policy URL |
|---|---|
| Status Saver for WhatsApp | https://tendulkark.github.io/tkstudioshq-legal/status-saver/privacy-policy.html |

## Adding a new app

1. Create `docs/<app-slug>/privacy-policy.html`.
2. Commit and push to `main` — GitHub Pages redeploys automatically.
3. Add a row to the table above.
